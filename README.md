# Судоку перебором с возвратом

Интерактивное объяснение того, как решить судоку алгоритмом backtracking (поиск с возвратом): шаг за шагом и с визуализацией.

**Сайт:** https://yeskermesovv.github.io/sudoku-solver/

Что есть на странице:

- правила судоку и кандидаты для любой клетки;
- дерево поиска на судоку 4×4;
- пять шагов алгоритма с подсветкой строк кода;
- визуализатор 9×9: текущая строка кода, стек вызовов, график глубины рекурсии, пошаговое управление и перемотка;
- сравнение числа шагов для разных головоломок и стратегий;
- полный код на Python и JavaScript.

Вся страница — один файл `index.html` без сборки и зависимостей. Чтобы посмотреть локально, откройте его в браузере.

Деплой на GitHub Pages делает workflow `.github/workflows/deploy.yml` при каждом пуше в `main`.
